# IR2-EMOA EMO 2027 working package

This package contains the current manuscript source, six diagnostic PNG plots in the same directory as the TeX source, and reproducibility scripts.

Public support repositories:
- https://github.com/emmerichmtm/IntegralR2ByPerspectiveMapping
- https://github.com/emmerichmtm/IntegralR2ContributionCalculator
- https://github.com/emmerichmtm/Integral-R2-EMOA

Performance assessment uses Integral R2, hypervolume, and Delta_p. `assess_six_problem_gallery.py` uses deterministic 10,000-point Pareto reference sets.
